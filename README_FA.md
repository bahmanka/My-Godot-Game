# Skyward: Operation Northern Wind — نسخه ۴

## اجرا
Godot 4.3 یا بالاتر (https://godotengine.org/download) ← Import ← `project.godot` ← F5.

## کنترل
| لمسی | صفحه‌کلید |
|---|---|
| دایره‌ی چپ: بالا و پایین = ارتفاع، چپ = کم کردن سرعت، راست = زیاد کردن سرعت | W S A D یا فلش‌ها |
| دکمه‌ی بزرگ: مسلسل (هر بار یک رگبار ۳ تایی) | Space |
| دکمه‌ی بمب: با هر لمس یک بمب | B |
| توقف | P |

## قواعد پرواز
- هواپیما بعد از برخاستن در یک‌سوم چپ صفحه ثابت است و فقط بالا و پایین می‌رود.
- زیر ۸۰٪ سرعت بیشینه افت ارتفاع شروع می‌شود (خط روشن روی نوار SPD). سرعت کمتر = فرود؛ روی باند فرود نرم، جای دیگر سقوط.
- بالاتر که بروید هوا رقیق می‌شود و توان صعود کم می‌شود؛ سقف سخت ندارد و دوربین دنبال هواپیما می‌رود.
- سوخت محدود است. باند متروکه‌ی میانی (علامت REFUEL روی نقشه) را برای سوخت‌گیری، پر کردن مهمات و تعمیر پیدا کنید و دوباره برخیزید. اگر بعد از آن ببازید، از همان باند ادامه می‌دهید.

## ارتقا و قفل
- فقط S.E.5a باز است. با هر مأموریت موفق، هواپیمای بعدی (I-16 ← Buffalo ← He 111) باز می‌شود.
- امتیاز مأموریت‌ها به اعتبار تبدیل می‌شود و در منوی UPGRADES برای مهمات، بمب، سوخت و زره خرج می‌شود. پیشرفت در فایل ذخیره می‌ماند.

## تنظیم‌ها
- `scripts/aircraft_data.gd`: سرعت، جان، مهمات (هر واحد = یک رگبار ۳ تایی)، بمب و سوخت هر هواپیما
- `scripts/terrain.gd`: طول مسیر، کوه‌ها، باندها
- `scripts/main.gd`: محل دشمنان و اهداف (تابع `_build_world`)، شدت آسیب

## محدودیت‌ها
- صدا ندارد. خروجی اندروید روی گوشی آزمایش نشده.
- اسپرایت‌ها از تصویر مرجع بریده و بزرگ‌نمایی شده‌اند؛ برای کیفیت نهایی نسخه‌ی با وضوح بالا لازم است.
- توازن سختی را فقط بازی کردن شما می‌تواند تنظیم کند.
